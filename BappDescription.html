PathHunter is an independently maintained Burp Suite extension derived from psychoPATH. It provides a customizable payload generator suitable for detecting a variety of file path vulnerabilities in file upload and download functionality:

  • File upload vulnerable to path traversal with the upload directory located inside the document root.
  • File upload vulnerable to path traversal with the upload directory outside the document root.
  • File upload not vulnerable to path traversal, but having the upload directory inside of the document root, with no direct links to the uploaded file exposed by the application.
  • Local file inclusion/arbitrary file read vulnerable to path traversal with non-recurrent filters involved.

PathHunter continues under GPL-3.0. Original project: psychoPATH by Julian Horoszkiewicz (https://github.com/ewilded/psychoPATH). Current project: https://github.com/Amirbarkhordari/PathHunter.
